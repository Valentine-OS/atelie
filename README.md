# Ateliê

Protótipo editorial em Astro, inspirado nas referências visuais fornecidas de Witch Hat Atelier. Nome, textos e datas são demonstrativos.

`npm install` · `npm run dev` · `npm run build`

Home: `/`. Manifesto: `/sobre/`. Layout responsivo. Os antigos escritos estão preservados em `archive/escritos`, fora das rotas publicadas.

As imagens fornecidas foram copiadas para `public/images`. Este protótipo não foi publicado. A configuração de GitHub Pages (domínio/base e workflow) deve ser definida com o repositório definitivo.
